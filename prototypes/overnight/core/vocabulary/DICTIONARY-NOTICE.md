The importer selects English entries and retains all supplied sense glosses, usage labels, etymology text, and form/alternative references. It omits media, examples, translations and other non-definition fields, and converts the data to an indexed SQLite database. These are formatting and selection changes; definitions are not generated. The adapted dictionary remains under CC BY-SA 4.0. This notice concerns dictionary data, not the application code.

Each displayed entry links to its original Wiktionary page, which provides contributor history. SQLite metadata records attribution, license, source URL, import date and entry count. The first prototype import uses the dump dated 2026-09-02, as described by Kaikki on 2026-10-21. The upstream URL is mutable; retain the downloaded archive when reproducing this exact installation.
